# GitHub Dev Card Generator

This project generates a beautiful GitHub developer card based on a public GitHub username. It uses an AI Agent powered by Gemini 2.5 Flash to analyze the profile and generate a tailored card.

## Project Structure

- `backend/`: FastAPI backend with Google Agent Development Kit and FastMCP tools.
- `frontend/`: Single-page HTML application using JavaScript to interface with the backend.
- `docker-compose.yml`: For local orchestration.

## Getting Started

Deploy the backend to Google Cloud Run, and the frontend via Cloud Run or any static site host.
